# UEAgent tool map

Which UEAgent tool does what, and the order a task calls them in. UEAgent's tools are the MCP tools of
the Unreal Editor's server (named `unreal` when it was connected from the editor's **MCP** menu). Your
client may show them with a prefix, such as `mcp__unreal__find_tools`.

## How to reach a tool

- By default your list holds the **core tools** and four meta-tools. Any other tool runs through
  `call_tool` with its `name` and `arguments`, or joins your list when `enable_toolset` adds its
  **pack** or its **domain**. Prefer a pack: a domain can add a hundred tools to your context.
- `find_tools` searches every tool by words of its name, in English ("spawn actor", "material
  parameter"). With `domain` it lists that domain's tools; with no arguments, the domains and the
  packs. `describe_tool` returns one tool's full schema before you call it.
- A client connected with `?tools=all` lists every tool directly: call them by name.

## The order of a task

1. **Find** what you will touch. `find_assets_by_name` finds an asset; from then on pass its full
   `/Game/...` path. The `actors` pack finds actors in the open level. Never guess a name.
2. **Read** before you write: `get_object_info` for an object's properties, `get_graph_nodes` for a
   graph.
3. **Change** it. `set_properties` writes any editable setting of an asset, an actor or a component;
   the graph tools edit a Blueprint's logic. Many small edits go in one `execute_batch` call.
4. **Check** each answer. A `readback` whose `verdict` is not `ok` means the call did not do what it
   reported: its `note` says why. Read the object again when the result matters.
5. **Compile** an edited Blueprint with `compile_blueprint` and read its messages.
6. **Save.** Most tools change the editor's memory only: `save_asset` writes an asset, `save_level` the
   level. Stop Play-in-Editor before compiling or saving.
7. **Undo** a mistake with `undo`.

`execute_python` runs Unreal's Python API, for what no tool does: search with `find_tools` first.

## Common tasks

| Task | Start with |
|---|---|
| Find an asset | `find_assets_by_name`; by type, tag or folder, the Asset domain |
| Read an object | `get_object_info`; a few named properties, `get_properties` |
| Change a light, fog, sky, post-process volume or any other setting | `set_properties` |
| Place, find or delete actors | the `actors` pack |
| Open or save a level, see what is unsaved | the `levels` pack |
| Play in the editor, capture the viewport | the `play` pack |
| Delete or duplicate an asset, see what uses it | the `assets` pack |
| Edit a Blueprint's logic | `get_graph_nodes`, `add_graph_node`, `connect_pins`, `set_pin_default_value`, `compile_blueprint` |
| Create a Blueprint, add variables, build several nodes at once | the `blueprint_authoring` pack |
| Read or change a data table row | the `data_tables` pack; whole tables, the DataAsset domain |
| Materials and material instances | the Material domain |
| Animation, skeletons, montages | the Animation domain |
| Menus and HUD (UMG) | the UI domain |
| Cinematics (Sequencer) | the Timeline domain |
| Particles (Niagara) | the Engine domain |
| Landscape, foliage, World Partition | the Level domain |
| Project settings, collision channels | the Config domain |
| Something no tool does | `execute_python`, after `find_tools` |
