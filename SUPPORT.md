# Getting help

- **Installing and connecting**: the [README](README.md) and [Clients](docs/clients.md).
- **Something does not work**: [Troubleshooting](docs/troubleshooting.md) and the [FAQ](docs/faq.md).
- **What a tool does**: the [tool reference](docs/tools/README.md).
- **A question**: ask in [Discussions, Q&A](https://github.com/CarlxsMG/UEAgent/discussions/categories/q-a).
- **An idea, or something you built with UEAgent**: [Discussions](https://github.com/CarlxsMG/UEAgent/discussions).
- **A bug, or a tool you need**: open an issue with the **Bug report** or **Feature request**
  template.
- **A vulnerability**: never in a public issue; see [SECURITY.md](SECURITY.md).
